# Series Lab Studio UI

Локальна вебмайстерня **Series Lab (by W3IR)** — інтерфейс для підготовки, рендеру, відбору та релізу серій.

- **URL**: http://127.0.0.1:5344/studio/ (також `/`)
- **Адреса сервера**: `127.0.0.1:5344` — з інших пристроїв недоступна (змінюється через `HOST` / `PORT`)
- **Ключі**: `SERIES_KEYS_FILE` → локальний `.env` у корені → `SERIES_DEFAULT_KEYS_FILE` (`src/keys.mjs`). У браузер іде лише «є / немає» та ім'я файлу.
- **Файли інтерфейсу**: `server/ui/index.html`, `app.js`, `style.css`, `i18n.js`, `locales/uk.js`, `locales/en.js`

---

## 1. Підказки й довідка

- **Підказка на кожній вкладці** — фіолетовий блок: одне речення «навіщо цей етап» + розгортання «Що робити, крок за кроком» (нумеровані кроки) + порада. Перемикач **Підказки** в шапці ховає всі блоки; вибір запам'ятовується.
- Пункти підказок генеруються з перекладів атрибутом `data-i18n-list="<tab>.hint.li"`: у списку стільки пунктів, скільки ключів `…li1`, `…li2`… є в локалі. Щоб додати пункт — додайте ключ в обидва файли `locales/*.js`, HTML міняти не треба.
- **❓ Довідка** (`renderHelp()` у `app.js`) будується з ключів `help.*` і працює навіть без сервера: що таке Series Lab, швидкий старт за $0, покроковий путівник (для кожного етапу — навіщо / що робити / що отримаєте / типові помилки / кнопка «Відкрити вкладку»), страховка, безкоштовний режим, словник (30 термінів), FAQ (14 питань), CLI, документи, запуск. Є **пошук** (фільтрує розділи й відкриває знайдені питання) і **зміст** (липка бічна панель; на вузьких екранах — рядок посилань).
- Друкована версія довідки — [GUIDE.md](./GUIDE.md).

## 2. Вкладки

### 1 · Огляд
Назва, ID пресету, кількість NFT, seed, двигун (зокрема **mock** — демо за $0), сила референсу → «Зберегти пресет». Факти готовності, стрічка етапів, «Безпека простими словами».

### 2 · Основа
Завантаження базових картинок (ролі: головна, лінія, style ref, extra), генерація кандидата з побажань, галерея `input/`, 🤖 **Vision Assist**. Заміна головної базової та «Видалити» переносять файли в кошик.

### 3 · Конструктор
Пак рис → «Які ключі крутити» → опції (value / weight / prompt) → keep / changeKeys / extraKeys / suffix → Style lock → ⚡ Matrix Preview (Flux, SDXL, Midjourney, Kontext, OpenAI) → Validate → «Зберегти промпт+трейти». Паки можна зберігати в бібліотеку.

### 4 · Рецепти
«Зібрати архів», таблиця (пошук, фільтр за лінією), редактор рецепта (✎, «Скинути», «Зберегти й переробити»), Diff-seed, звіт рідкості, матриця синергії рис.

### 5 · Генерація
Двигун, сила, паралельність (1x / 2x / 3x), що генерувати (пілот, лише номери, перші N, усі відсутні, перегенерувати). «Порахувати (безкоштовно)» показує кількість, ціну, **витрачене сьогодні** і денну межу; «Згенерувати» розблоковується лише після оцінки. Живий SSE-прогрес з мініатюрами. Перегенерація зберігає попередню картинку як версію; якщо рушій падає 5 разів поспіль — batch зупиняється, у статусі видно причину.

### 6 · Відбір
Набір, порівняння з другим набором, фільтри, ✓ Лишити / ↻ Переробити (зберігаються в `marks.json`), лайтбокс, 🤖 Triage (евристика $0 або AI Vision), «Перегенерувати відхилені». Позначка **v·N** на плитці відкриває вікно версій: перегляд, «Зробити поточною», «У кошик».

### 7 · Експорт
CSV / TXT промптів, Manifest CSV, **Mint-ready ZIP** (OpenSea, Magic Eden, LaunchMyNFT, Ordinals; лише keep; upscale 2×; динамічні медіа), 📌 IPFS (Pinata), попередній перегляд `1.json`, 🔐 Provenance Hash, 📦 LoRA Dataset, ⬇ Showcase, 🚀 Release Hub з чеклістом, NFT checklist.

### 💰 Ресурси
Картки ключів, **💰 Витрати сьогодні** (з `out/render-log.jsonl`, розбивка за рушіями, денна межа), **🗑️ Кошик** (відновити / видалити назавжди з підтвердженням другим натиском), ⚡ перевірка підключень до рушіїв.

## 3. Дизайн

- Токени кольорів, радіусів, тіней і фокусу — у `:root` (`style.css`, блок «Design refresh»). Фірмовий градієнт `--grad` — для активної вкладки, номерів кроків і головних кнопок.
- **Головні дії** мають клас `btn primary` (градієнт). `btn danger` — лише для незворотних дій (наприклад, «Видалити назавжди»).
- Видимий фокус для клавіатури (`:focus-visible`), `accent-color` для чекбоксів і повзунків, `prefers-reduced-motion` вимикає анімації.
- Адаптивність: до 900 px довідка стає однією колонкою; до 720 px меню вкладок гортається горизонтально, відступи зменшуються. Горизонтальної прокрутки сторінки на ширині телефона немає.

## 4. Локалізація

- Мови: `uk` (за замовчуванням) і `en`; перемикач UK / EN у шапці, вибір у `localStorage` (`series-lab-locale`).
- Атрибути: `data-i18n`, `data-i18n-html`, `data-i18n-title`, `data-i18n-placeholder`, `data-i18n-aria`, `data-i18n-list`.
- Обидві локалі мають однаковий набір ключів; якщо ключа немає в `en`, береться `uk`.

## 5. Безпека

1. Сервер слухає лише `127.0.0.1`. Запити до `/api/*` з чужим `Host`, з іншого `Origin` або POST без `Content-Type: application/json` отримують `403` (`server/guard.mjs`).
2. Значення ключів не передаються в браузер.
3. Платні виклики — лише за явною дією, з межею витрат і журналом; видалене йде в кошик; перегенерація зберігає версії.
