# Series Lab Studio UI

Вебмайстерня **Series Lab (by W3IR)** — підготовка, рендер, відбір і реліз серій.

- **URL**: http://127.0.0.1:5344/studio/ (також `/`; у public без сесії — `/login`)
- **Адреса сервера**: типово `127.0.0.1:5344` (`HOST` / `PORT`)
- **Ключі**: `.env` / `SERIES_KEYS_FILE` — у браузер лише «є / немає»
- **Файли**: `server/ui/index.html`, `app.js`, `style.css`, `i18n.js`, `locales/uk.js`, `locales/en.js`, `locales/tips.mjs`
- **Вхід**: лише гаманець (MetaMask / Coinbase / Phantom)

---

## 1. Підказки й довідка

- Фіолетові блоки на вкладках + `data-i18n-list`; перемикач **Підказки**.
- Hover на опціях — `applyTips()` / `locales/tips.mjs` (`data-i18n-tip`, `<key>.tip`).
- **Підказки залежать від вибору.** Показується лише те, що стосується обраного варіанта: у «Експорті» профіль (Magic Eden / LaunchMyNFT → Solana, `ar://`, кнопка Arweave; OpenSea → EVM, `ipfs://`/https; Ordinals → без сховища й префіксів), у порадникові деплою — мережа. Мережа спільна: профіль Експорту, «Мережа» в наборі деплою і в наборі маркетплейсу синхронізовані (зміна одного оновлює решту; типово Solana). Зібраний ZIP, гайд і статуси належать мережі, для якої їх зібрано: при зміні мережі чи профілю вони очищаються, треба зібрати наново. Підказка профілю — `export.profileHint.<профіль>`, плейсхолдери — `export.creator.ph.<мережа>`.
- **❓ Довідка** з `help.*`; пошук і зміст. Друкована версія — [GUIDE.md](./GUIDE.md).

## 2. Вкладки

### 1 · Огляд
«Почати серію», «Спін-оф», «Зберегти пресет», факти, стрічка етапів.

### 2 · Основа
Upload / wish→generate, Vision Assist; видалення → кошик.

### 3 · Конструктор
Паки, опції, фіксатор стилю (style lock), попередній перегляд матриці, «Перевірити», «Зберегти промпт+трейти».

### 4 · Рецепти
«Зібрати тексти», хвилі, diff архівів, редактор, рідкість.

### 5 · Генерація
«12 пілотів — порахувати» або «Порахувати (безкоштовно)», потім «Згенерувати…». До оцінки кнопка вимкнена. Сила референсу типово 0.45. «Скласти шари» (`#g-compose`) викликає `POST /api/compose`: базова картинка з `input/` і PNG з `layers/<риса>/<значення>.png` → `out/layers`. Промпти лишаються. Кредити не списуються.

### 6 · Відбір
«✓ Лишити» / «↻ Переробити», порівняння, triage, «Знайти схожі», версії, галочка «Мініатюра 64px поруч».

### 7 · Експорт
«Перевірити чекліст», «Зібрати ZIP», «Зібрати архів випуску». Профіль Magic Eden — лише Solana.

### Деплой
«Зібрати набір деплою». Типовий пункт — «Solana (Core Candy Machine, спочатку devnet)». Порадник офлайн. Опис колекції — поле на цій вкладці. Поле allowlist (`#d-allowlist`) видно лише для Solana і Solana (Sugar); для EVM і Bitcoin воно ховається і в запит не йде. Набір містить `hidden.json`, `hidden.png` і чернетку `hidden-settings.json` (хеш порожній до `series hidden`).

### Маркет
«Зібрати набір маркетплейсу». Solana: Magic Eden і Tensor. EVM: OpenSea. Bitcoin: Ordinals.

### Адмін
Лише адмін-гаманець. Ресурси (ключі, кошик) / **Економіка** / Статистика / Помилки. Економіка — [ECONOMY.md](./ECONOMY.md).

### Кредити (public)
Шапка: гаманець · чіп **«Баланс»** (жовтий, якщо < 10 кр.) · **«＋ Купити»** · Вийти. Обидві кнопки відкривають вікно поповнення (`#topup-overlay`, лежить на рівні `body`, тож видиме з будь-якої вкладки): пакети (кнопка «Оплатити USDC» створює замовлення) → панель замовлення (точна сума, адреса, автоопитування кожні ~8 с; адміну — ще пакет «Тест») → бонус холдера / реферали / історія. Відмова 402 «не вистачає кредитів» відкриває вікно сама. Зарахування показує тост. API — [API.md](./API.md).

## 3. Дизайн

Токени в `style.css`; `btn primary`; `:focus-visible`; адаптив; `[data-tip]` tooltips. `--border` дорівнює `--line` (розділювачі і доріжка прогресу).

## 4. Локалізація

`uk` / `en`; атрибути `data-i18n*`; tips uk/en парні.

## 5. Безпека

1. Loopback за замовчуванням; `SERIES_MODE=local` не слухає поза loopback.
2. Guard: Host / Origin / JSON Content-Type.
3. Public: сесія `w3ir_session`, кредити, `data/users/<wallet>/`.
4. Значення API-ключів і сид-фрази в браузер / на диск як секрети користувача — ні.
