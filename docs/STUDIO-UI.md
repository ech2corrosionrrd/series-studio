# Series Lab Studio UI

Вебмайстерня **Series Lab (by W3IR)** — підготовка, рендер, відбір і реліз серій.

- **URL**: http://127.0.0.1:5344/studio/ (також `/`; у public без сесії — `/login`)
- **Адреса сервера**: типово `127.0.0.1:5344` (`HOST` / `PORT`)
- **Ключі**: `.env` / `SERIES_KEYS_FILE` — у браузер лише «є / немає»
- **Файли**: `server/ui/index.html`, `app.js`, `style.css`, `i18n.js`, `locales/uk.js`, `locales/en.js`, `locales/tips.mjs`
- **Вхід**: лише гаманець (MetaMask / Coinbase / Phantom)

---

## 1. Підказки й довідка

- Фіолетові блоки на вкладках + `data-i18n-list`; перемикач **Підказки**.
- Hover на опціях — `applyTips()` / `locales/tips.mjs` (`data-i18n-tip`, `<key>.tip`).
- **❓ Довідка** з `help.*`; пошук і зміст. Друкована версія — [GUIDE.md](./GUIDE.md).

## 2. Вкладки

### 1 · Огляд
«Почати серію», «Спін-оф», «Зберегти пресет», факти, стрічка етапів.

### 2 · Основа
Upload / wish→generate, Vision Assist; видалення → кошик.

### 3 · Конструктор
Паки, опції, styleLock, Matrix Preview, Validate, збереження.

### 4 · Рецепти
«Зібрати тексти», хвилі, diff архівів, редактор (`overrides`), рідкість / синергія.

### 5 · Генерація
«12 пілотів — порахувати», lock Generate після оцінки, DNA-блок, SSE, версії.

### 6 · Відбір
keep/redo, порівняння, Triage, «Знайти схожі», версії `v·N`.

### 7 · Експорт
Архів випуску → ZIP → «Далі · портал запуску»; інші ZIP/CSV/IPFS/Showcase/LoRA/Hub/checklist.

### Адмін
Лише адмін-гаманець. Ресурси (ключі, кошик) / **Економіка** / Статистика / Помилки. Економіка — [ECONOMY.md](./ECONOMY.md).

### Кредити (public)
Шапка: гаманець · чіп **«Баланс»** (жовтий, якщо < 10 кр.) · **«＋ Купити»** · Вийти. Обидві кнопки відкривають вікно поповнення (`#topup-overlay`, лежить на рівні `body`, тож видиме з будь-якої вкладки): пакети (кнопка «Оплатити USDC» створює замовлення) → панель замовлення (точна сума, адреса, автоопитування кожні ~8 с; адміну — ще пакет «Тест») → бонус холдера / реферали / історія. Відмова 402 «не вистачає кредитів» відкриває вікно сама. Зарахування показує тост. API — [API.md](./API.md).

## 3. Дизайн

Токени в `style.css`; `btn primary`; `:focus-visible`; адаптив; `[data-tip]` tooltips.

## 4. Локалізація

`uk` / `en`; атрибути `data-i18n*`; tips uk/en парні.

## 5. Безпека

1. Loopback за замовчуванням; `SERIES_MODE=local` не слухає поза loopback.
2. Guard: Host / Origin / JSON Content-Type.
3. Public: сесія `w3ir_session`, кредити, `data/users/<wallet>/`.
4. Значення API-ключів і сид-фрази в браузер / на диск як секрети користувача — ні.
