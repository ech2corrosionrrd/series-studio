# Базова картинка(и) серії та Vision Assist

Канонічний термін продукту Series Lab: **базова картинка(и) серії** (series base image(s)).

Базова картинка є візуальним якорем для всієї колекції. Вона визначає композицію, риси обличчя, ракурс та стилістику, на яку генератор надалі «надягає» змінні трейти.

Роль **`primary`** у UI = **головна базова**.

---

## 1. Способи створення або додавання бази

1. **Завантаження файлів з диска** (`POST /api/base/upload`):
   - Підтримуються формати PNG, JPG, JPEG, WebP.
   - Рекомендований розмір: квадрат від 1024×1024 px.
   - Чистий суб'єкт без написів, логотипів чи водяних знаків.
2. **Генерація за побажанням** (`POST /api/base/generate`):
   - Опис бажаного образу через Wish prompt.
   - Підтримка режимів: з нуля (txt2img) або від наявної головної базової (edit/img2img).
   - Обов'язкова перевірка через Prompt Lint перед генерацією.
3. 🤖 **Vision Assist (Авторозбір стилю)** (`POST /api/base/analyze`):
   - Автоматичний аналіз завантаженої базової картинки за допомогою мультимодальних моделей (OpenAI GPT-4o або Anthropic Claude Vision).
   - Автоматичне вилучення структури `styleLock`: кут зйомки (`angle`), освітлення (`light`), настрій (`mood`), кадрування (`framing`) та палітра кольорів.
   - Генерація початкових пропозицій рис (архетип персонажа, фон, ключові атрибути) для перенесення в Конструктор.
   - Автономний евристичний фолбек за відсутності API-ключів.

---

## 2. Ролі файлів у папці `input/`

| Роль (технічна) | У інтерфейсі | Ім'я файлу | Призначення |
|-----------------|--------------|------------|-------------|
| **`primary`** | Головна базова | `primary.png` (`.jpg`, `.webp`) | Основний референс для всієї серії |
| **`line`** | Базова для лінії | `base-<lineId>.*` | Індивідуальний референс під конкретну лінію (архетип) |
| **`style`** | Стиль-референс | `style-*.*` | Додатковий референс стилю чи освітлення |
| **`extra`** | Додаткова | `extra-*.*` | Запасні варіанти або деталі |

*Примітка щодо сумісності*: старі файли з назвою `mother.*` автоматично розпізнаються сервером як головна базова, проте нові збереження записуються виключно як `primary.*`.

*Нічого не губиться*: коли ви призначаєте іншу головну базову, завантажуєте файл з уже зайнятим іменем або натискаєте «Видалити», попередній файл переїжджає в кошик `out/trash/`. Відновити його можна в Адмін → Ресурси → Кошик (записи зберігаються `SERIES_TRASH_DAYS`, за замовчуванням 30 днів).

## 3. Нижній шар складання PNG

Та сама головна базова (`input/primary.png`) — нижній шар, коли на Генерації натискаєте «Скласти шари» або запускаєте `series compose <архів> --layers <тека> --base input/primary.png`. Поверх неї лягають `layers/<ключ риси>/<значення>.png`. Промпти на рецептах лишаються. Кредити за складання не списуються. Результат — `out/layers` і `dna.json`.

## 4. Рекомендації щодо якості

- **Один чіткий суб'єкт**: портрет або центральний об'єкт без зайвих дрібних деталей на фоні.
- **Нейтральний фон**: спрощує генератору заміну фонів за трейтами (`background`).
- **Стійкість стилю**: одна сильна, деталізована головна базова забезпечує набагато вищу однорідність колекції, ніж використання багатьох різнорідних референсів.
