# Послідовність етапів Series Lab

Кожен етап має **оптимальний** набір (те, що роблять майже завжди) і **широкий** (розширений спектр / advanced).  
Поля з попереднього етапу **не дублюємо** — лише читаємо або повертаємось на відповідну вкладку для внесення правок.

Термінологія: **базова картинка(и) серії**; `primary` = головна базова.  
Пояснення простими словами для кожного етапу — [GUIDE.md](./GUIDE.md) і вкладка «❓ Довідка».

---

| # | Етап | Оптимально | Широкий спектр (Advanced) | Не робимо тут |
|---|------|------------|---------------------------|---------------|
| 1 | **Огляд (Overview)** | Назва, id, розмір, seed, двигун / сила; «Почати серію» / «Зберегти» / «Спін-оф». | Автоматичне відновлення workspace (`workspace/current.json`). | Промпти, трейти, запуск рендеру. |
| 2 | **Основа (Base)** | Головна базова картинка (`primary.png` через upload або wish→generate). | Лінійні бази (`base-<line>.*`), додаткові рефи (`style-*`, `extra-*`), 🤖 **Vision Assist**. | Назва/розмір/seed, мінт. |
| 3 | **Конструктор (Constructor)** | Шаблон промпту, пак рис, **редактор опцій**, `styleLock`. | Бібліотека паків, матриця LoRA / тегів під різні двигуни. | Повторення параметрів ідентичності. |
| 4 | **Рецепти (Recipes)** | «Зібрати тексти» (без кредитів), таблиця DNA, diff-seed, рідкість. | Хвилі поставки, diff двох архівів, точкова правка (`overrides`), синергія рис. | Завантаження картинок, оплата. |
| 5 | **Генерація (Generate)** | «12 пілотів — порахувати» / оцінка → генерація; DNA-блок. «Скласти шари» з готових PNG (`layers/`) поруч із промптами. | Паралельність, режими selection, SSE, `mock`, межа витрат, автостоп, версії. | Зміна структури ДНК / серії. |
| 6 | **Відбір (Review)** | keep / redo, версії `v·N`, redo marked. | Порівняння наборів, AI Triage, «Знайти схожі». | Публічний мінт / клейм. |
| 7 | **Експорт (Export)** | **Архів випуску** («Перевірити чекліст» → «Зібрати ZIP», за бажанням лише позначені «Лишити») → портал запуску. | Інші ZIP-профілі, CSV, Arweave (Irys), вітрина, датасет LoRA, хаб випуску. | Прямий ончейн-мінт з Lab. |
| — | **Деплой** | «Зібрати набір деплою». Типово Solana: Core Candy Machine (`cm-config.json`), спочатку devnet. Порадник запуску над кнопкою. | EVM: пакет Thirdweb. Ordinals: інструкція, спочатку signet. Sugar — пункт «Solana (Sugar, застарілий)», файли в `sugar/`. | Підпис транзакції і приватний ключ. |
| — | **Маркет** | «Зібрати набір маркетплейсу». Solana: Magic Eden і Tensor. EVM: OpenSea. Bitcoin: Ordinals. | Розміри банера, аватара й обкладинки в `SIZES.json`. | Лістинг через API майданчика. |
| — | **Адмін** | Ресурси (ключі, кошик), **Економіка**, статистика, помилки. | Перевірка рушіїв. У public — гаманці з `ADMIN_WALLETS` (якщо змінну не задано — типовий оператор). | Показ секретів ключів. |
| — | **Довідка** | Путівник 1 → 7, далі Деплой і Маркет, швидкий старт, страховка, словник, FAQ. | CLI, перелік docs. | — |

---

## Принцип руху по майстерні

- **Рух по кроках** 1 → 2 → 3 → 4 → 5 → 6 → 7, далі вкладки «Деплой» і «Маркет». Прямі вкладки лишаються.
- Повернення назад — лише у випадку необхідності змінити першоджерело даних (Огляд для seed/size, Основа для базового референсу, Конструктор для правил промпту).
