# Послідовність етапів Series Lab

Кожен етап має **оптимальний** набір (те, що роблять майже завжди) і **широкий** (розширений спектр / advanced).  
Поля з попереднього етапу **не дублюємо** — лише читаємо або повертаємось на відповідну вкладку для внесення правок.

Термінологія: **базова картинка(и) серії**; `primary` = головна базова.  
Пояснення простими словами для кожного етапу — [GUIDE.md](./GUIDE.md) і вкладка «❓ Довідка».

---

| # | Етап | Оптимально | Широкий спектр (Advanced) | Не робимо тут |
|---|------|------------|---------------------------|---------------|
| 1 | **Огляд (Overview)** | Назва, id пресету, розмір серії, seed, базовий двигун / сила референсу, збереження пресету. | Автоматичне відновлення workspace (`workspace/current.json`). | Промпти, трейти, запуск рендеру. |
| 2 | **Основа (Base)** | Головна базова картинка (`primary.png` через upload або wish→generate). | Лінійні бази (`base-<line>.*`), додаткові рефи (`style-*`, `extra-*`), 🤖 **Vision Assist** (авторозбір стилю та трейтів через GPT-4o/Claude). | Назва/розмір/seed, мінт. |
| 3 | **Конструктор (Constructor)** | Шаблон промпту (keep/change/extra/suffix), вибір паку рис, **редактор опцій трейтів** (value, weight, prompt), `styleLock`. | Збереження та експорт нових паків у бібліотеку (`libraries/traits/`), матриця LoRA / тригер-тегів під різні двигуни (Flux, SDXL, Midjourney). | Повторення параметрів ідентичності (вони лише для читання). |
| 4 | **Рецепти (Recipes)** | Збирання архіву (`POST /api/build`), таблиця DNA/промптів, перевірка стабільності `diff-seed`, звіт рідкості. | Редагування окремих рецептів, захист від конфліктних пар трейтів (`rules.conflicts`), розрахунок рідкості Scorecard. | Завантаження картинок, оплата. |
| 5 | **Генерація (Generate)** | Безкоштовна оцінка (ціна + витрачене сьогодні + денна межа), лінтинг промптів, пілот, запуск рендеру. | Паралельність 1x/2x/3x, режими (`pilot`, `only`, `first`, `missing`, `redo`, `force`), живий SSE-прогрес, демо-двигун `mock` ($0). Перегенерація зберігає версії; межа `SERIES_SPEND_CAP_USD`; автостоп після 5 помилок поспіль. | Зміна структури ДНК чи параметрів серії. |
| 6 | **Відбір (Review)** | Перегляд згенерованих сетів, маркування `keep` / `redo`, швидкий повторний запуск відхилених, вибір поточної версії (`v·N`). | Порівняння двох наборів поруч (side-by-side), 🤖 **AI Auto-Triage & Smart Critic** (оцінка 1–10, аналіз дефектів анатомії/стилю, авто-застосування Keep/Redo). | Публічний мінт / клейм. |
| 7 | **Експорт (Export)** | Промпти (JSON / CSV / TXT), гуртовий CSV маніфест, перевірка NFT чекліста. | Mint-ready ZIP (ERC-721 / Metaplex / Ordinals), 2x upscale (`sharp`), **динамічні медіа** (`animation_url`), **IPFS Pinata Dispatcher**, **Standalone HTML Showcase**, **Release & Deployment Hub** (`sugar.json` / `thirdweb.json`). | Пряме списання коштів чи мінт з головної. |
| — | **Ресурси** | Перевірка наявності ключів API (без показу значень), витрати сьогодні, кошик. | Діагностика швидкості рушіїв, відновлення / остаточне видалення з кошика. | Показ приватних ключів/токенів. |
| — | **Довідка** | Путівник 1 → 7 простими словами, швидкий старт за $0, страховка, словник, FAQ, пошук. | Команди CLI, перелік документації. | — |

## Принцип руху по майстерні

- **Рух тільки вперед по кроках** (1 → 2 → 3 → 4 → 5 → 6 → 7).
- Повернення назад — лише у випадку необхідності змінити першоджерело даних (Огляд для seed/size, Основа для базового референсу, Конструктор для правил промпту).
