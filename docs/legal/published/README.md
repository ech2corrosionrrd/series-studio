# Затверджені правові тексти (публікуються на сайті)

**Стан на 05.10.2026:** за рішенням власника опубліковано **бета-версію** Умов і Політики (стадія розробки й тестування, «як є», користування означає згоду). Тексти не проходили перевірку юриста: це свідомий вибір власника для ранньої стадії; після затвердження юристом їх варто замінити. Контакт у текстах: w3ir@pm.me (змініть, якщо потрібна інша адреса). Застосовне право в текстах не визначене до реєстрації оператора.

Сторінки **Умови** (`/terms/`, `/en/terms/`) і **Політика конфіденційності** (`/privacy/`, `/en/privacy/`) з'являються на https://studio.w3ir.io **лише** тоді, коли сюди покладено затверджені юристом тексти. З чернеток `docs/LEGAL-DRAFT*.md` нічого не публікується.

## Як опублікувати

1. Юрист затверджує тексти. Візьміть чернетки `docs/LEGAL-DRAFT.md` (uk) і `docs/LEGAL-DRAFT.en.md` (en), заповніть усе в `` `[квадратних дужках]` ``, розділіть на окремі файли.
2. Покладіть сюди чотири файли (Markdown):

   | Файл | Сторінка |
   |---|---|
   | `terms.uk.md` | https://studio.w3ir.io/terms/ |
   | `terms.en.md` | https://studio.w3ir.io/en/terms/ |
   | `privacy.uk.md` | https://studio.w3ir.io/privacy/ |
   | `privacy.en.md` | https://studio.w3ir.io/en/privacy/ |

   Політику повернення зручно тримати розділом усередині Умов.
3. Кожен файл починається з `# Заголовок` (це назва сторінки й посилання у футері). Дозволено: заголовки `##`/`###`, абзаци, списки `-` і `1.`, цитати `>` (виходять як примітка), таблиці, блоки коду, `**жирний**`, `[текст](https://…)` і `mailto:`. Інший HTML не підтримується.
4. Перевірте локально: `npm run build:site`, відкрийте `dist/site/terms/index.html`. У консолі побачите, якщо щось пропущено.
5. Змердж у `main`: workflow `deploy-site.yml` запускається при зміні цієї теки й викладає сайт. У футері всіх сторінок з'являться посилання.

## Правила, які перевіряє збірка

- Сторінка публікується, лише якщо є **обидві мови**. Інакше збірка пише попередження й сторінку пропускає.
- Файл із `` `[плейсхолдером]` `` (текст у квадратних дужках усередині зворотних лапок, як у чернетках) **не публікується**: так недописаний документ не потрапить на сайт.
- Без файлів у цій теці сайт збирається як зараз, без посилань у футері.

Посилання на ці сторінки варто додати також у вхід у майстерню (`/login`) і, якщо юрист вимагатиме, зробити явну згоду при першому вході: це окрема доробка, яку треба погодити з текстами.
