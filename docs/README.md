## 🏛 Архітектурні принципи

1. **Lab → Studio → Release**:
   - **Lab**: Математичне ядро, детермінований RNG, схеми даних, валідація, генерація DNA.
   - **Studio**: Інтерфейс майстерні, робота з базою, лінтинг, промпти, багатопотоковий рендер, живий SSE прогрес, галерея з AI-тріажем.
   - **Release**: Експорт готових бандлів, IPFS/Arweave диспетчер, генерація конфігів для деплою (`sugar.json`, `thirdweb.json`), автономний HTML візуальний пруф & Scorecard.
2. **Безпека та Non-Custodial архітектура**:
   - Жодні приватні ключі або сид-фрази не збираються, не зберігаються і не передаються на сервер.
   - Деплой виконується через офіційні інструменти (Metaplex Sugar CLI, Thirdweb CLI, портали OpenSea/Magic Eden).
3. **Термінологія**:
   - Канонічний термін: **«базова картинка(и) серії»** / series base image(s).
   - Роль `primary` = **головна базова**. Уникаємо застарілих термінів типу «мати»/mother.
