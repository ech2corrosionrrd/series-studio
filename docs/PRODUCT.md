# Series Lab — бачення продукту

Оновлено: **29.10.2026** (v1.25.0). Це опис того, чим Series Lab є для людини, яка хоче свою колекцію. Технічні межі з іншими продуктами — [BOUNDARIES.md](./BOUNDARIES.md). Економіка кредитів — [ECONOMY.md](./ECONOMY.md). План наступних змін за зовнішнім дослідженням колекцій — [RECOMMENDATIONS.md](./RECOMMENDATIONS.md) (документ плану, не зміна продукту).

## Місія

Series Lab допомагає людині створити NFT-колекцію з нуля й отримати перевірений архів, готовий до публікації, та дає все потрібне, щоб сама безпечно задеплоїти її зі свого гаманця й виставити на маркетплейсі. Ключі й кошти ми не тримаємо.

## Для кого

Будь-хто, хто хоче власну колекцію: від людини, яка вперше чує слово «метадані», до автора, який уже деплоїв дропи. Кожен бере лише ті етапи, які йому потрібні. Решту можна пропустити.

## Принципи

1. **Людина підписує, деплоїть і виставляє сама** — зі свого гаманця й свого акаунта на маркетплейсі.
2. **Ми не тримаємо ключі й кошти.** Сервер не приймає seed-фразу чи приватний ключ. Оплата кредитів — USDC у Solana на публічну адресу, без посередника; це поповнення майстерні, не гаманець колекції.
3. **Етапи окремі.** Генерація, відбір, архів, набір деплою, набір маркетплейсу можна пройти всі або лише потрібні.
4. **Два входи в той самий інструмент.** Шлях новачка: Lab → Studio → Випуск → Набір деплою → Набір маркетплейсу. Досвідчений відкриває будь-яку вкладку зверху.
5. **Кожен платний етап має ціну до дії.** Ціна = собівартість + невелика фіксована маржа. Числа живуть у конфігурації, не в «приблизно стільки зараз на біржі».
6. **ШІ не ховаємо.** Експорт позначає зображення як створені ШІ в метаданих, а підпис C2PA користувач ставить сам на своєму ПК ([C2PA.md](./C2PA.md)).

## Етапи

| Етап | Що людина отримує | Хто платить мережі |
|---|---|---|
| Генерація | Картинки за рецептами | API рушія — з кредитів Lab. Мережа тут ні до чого |
| Відбір | Keep / redo, видалення кадру (другий клік) і прибирання з набору без знищення файлу. Евристичний triage безкоштовний; AI triage — за тарифом бачення | — |
| Архів | ZIP: картинки, метадані стандарту мережі, обкладинка, опис, роялті, звіт рідкості, README з наступними кроками. Позначка «готовий» лише після перевірки | Arweave (Irys), якщо людина сама запускає завантаження |
| Набір деплою | Конфіг і команди. Solana: Core Candy Machine (`cm-config.json` і `assets/`), спочатку devnet; Sugar лише в `sugar/` як застарілий. EVM: пакет Thirdweb, спочатку тестнет. Ordinals: інструкція, спочатку signet | Людина, зі свого гаманця |
| Набір маркетплейсу | Чеклісти, текст лістингу, банер / аватар / обкладинка в заданих розмірах, поради з верифікації | Людина, зі свого акаунта майданчика |

## Економіка етапу

```
ціна_етапу = собівартість + фіксована_маржа
кредити = ceil(ціна_етапу / STAGE_USD_PER_CREDIT)
```

`STAGE_USD_PER_CREDIT` типово **0.03** — підлога найдешевшого пакета (Профі). Генерація лишається на тарифі рушіїв (`creditCost`, підлога `ceil(costUsd × 50)`). Евристичний відбір типово **$0**. Архів, набір деплою й набір маркетплейсу — невеликі фіксовані суми (типово 1 і 2 кредити). Завантаження в Arweave додається лише тоді, коли ви його запускаєте.

Оцінка газу / ренти деплою — **окрема** від кредитів. Це формула з констант у `.env` (`DEPLOY_SOL_*`, `DEPLOY_EVM_*`, `DEPLOY_ORDINALS_*`). Доларів немає, якщо власник не задав курс. Живих цін з біржі чи RPC ми не підставляємо.

Адмін → Економіка показує по кожному етапу операції, собівартість, виручку (кредити × $/кр) і різницю.

## Мережі

Усі вже підтримані мережі лишаються: Solana (Core Candy Machine; Sugar лише як застарілий), EVM (ERC-721 / Thirdweb / OpenSea), Bitcoin Ordinals.

**Solana — перша за пріоритетом** (набір деплою й маркетплейсу відкриваються на ній). EVM і Bitcoin не прибираємо.

## Поза продуктом

- Ми **не деплоїмо** колекцію за людину і **не продаємо** її з її акаунта.
- **Дроп #2 / `src/platform/vault.mjs`** (ми самі шлемо NFT покупцям) — не ядро. Лишається вимкненим: фонове звіряння не стартує без `VAULT_WALLET_ADDRESS`, тригера видачі немає. Умикати лише окремим рішенням, не в цьому продукті. Див. [STANDALONE.md](./STANDALONE.md).

## Дорожня карта (свідомо не в цій зміні)

Завелике або суперечить принципу «ключі й кошти не тримаємо»:

1. **Живий оракул газу / ренти.** Зараз лише формула й константи власника. Підключення RPC за ціною мережі — окреме рішення, щоб не показувати вигаданий курс.
2. **Деплой з браузера Lab** (підпис Core Candy Machine або Thirdweb усередині майстерні). Зараз людина запускає CLI або кабінет Thirdweb у себе. Інакше легко зісковзнути в зберігання ключа.
3. **Лістинг через API Magic Eden / Tensor / OpenSea.** Людина публікує зі свого акаунта. Набір лише готує текст, розміри й чекліст.
4. **Перцептивний дубль як помилка воріт.** Точний SHA-256 уже блокує. Схожі, але різні файли лишаються інструментом Відбору (`/api/gallery/dupes`), не жорстким стопом.
5. **JPEG/WebP без sharp.** PNG змінюємо власним декодером. Інші формати обкладинки — якщо встановлено опційний `sharp`, інакше попередження в наборі.
6. **Оплата етапу окремим переказом USDC** замість кредитів. Потік Phantom/USDC не змінювали.
7. **Дроп #2 / сейф.** Лишається вимкненим.
