### Зовнішнє тестування через тунель (на час розробки)

Сервер лишається на ПК; тестувальники заходять через іменований тунель Cloudflare (швидкі `trycloudflare.com` з цієї мережі заблоковані провайдером).

1. **Один раз** — DNS-запис (потрібен `~/.cloudflared/cert.pem`):
   `cloudflared tunnel route dns w3ir-tunnel lab-dev.w3ir.space`
2. **Запуск:** `npm run lab:tunnel` (Ctrl+C зупиняє і сервер, і тунель). Сервер слухає `127.0.0.1:5345`; постійний `.env` не змінюється — `AUTH_DOMAIN`/`AUTH_URI`/`SERIES_ALLOWED_HOSTS` підставляються лише на час запуску.
3. **Запрошення обов'язкові:** гаманці тестувальників — у файлі `.tunnel-wallets` (по одному в рядок, у `.gitignore`) або `TUNNEL_ALLOWED_WALLETS=гаманець1,гаманець2 npm run lab:tunnel`. Без списку діє лише `ADMIN_WALLETS` із `.env`; порожній список означав би «пускати всіх» — скрипт у такому разі не запускається. Після змін списку перезапустіть скрипт.
4. **Захисти режиму:** ліміт витрат `TUNNEL_SPEND_CAP_USD` (типово $5/день, бо ключі справжні), локальний GPU вимкнено (`SERIES_LOCAL_GPU=0`), cookie `Secure`. Вітальні кредити видаються і гаманцям з порожнім балансом (`WELCOME_REQUIRE_BALANCE=0` лише в цьому режимі — доступ і так за запрошеннями).
5. **З телефона:** у звичайному Chrome/Safari гаманця немає — на `/login` з'являються кнопки, що відкривають сторінку в застосунку Phantom / MetaMask / Coinbase Wallet (він має бути встановлений). Або вручну: відкрити вбудований браузер застосунку й ввести адресу.
6. **Оплата USDC у Solana** (`SOLANA_PAY_RECIPIENT`) працює з будь-якої країни й не залежить від тунелю (вебхуків нема): кредити зараховує фоновий цикл (кожні 45 с) і автоопитування у вікні «Купити». Для перевірки адміном є пакет «Тест» $0.10 (`SOLANA_PAY_TEST_PACK=1`) — прибрати з `.env` після тесту.

## Після закінчення розробки — що робити (лише за командою)

1. **Зафіксувати `main` на GitHub** (цей реліз) і прогнати `npm test` локально.
2. **Не** підключати домени автоматично.
3. Коли власник відкриє хостинг:
   - оновити образ на `next.w3ir.io` з нового `main` (`deploy/series-lab/upload.sh` / phase3) **або** власний домен за [DEPLOY-PLATFORM.md](./DEPLOY-PLATFORM.md);
   - перевірити `SERIES_ALLOWED_HOSTS`, бекап cron, запас RAM;
   - увімкнути offsite лише з `BACKUP_RCLONE_REMOTE` + `BACKUP_PASSPHRASE`.

## Рекомендації (коли відкриють хостинг)

### 1. Лендінг лишити на Cloudflare Pages

Статичний сайт, автодеплой з `main`, DNS у тій самій зоні.

### 2. Платформа — на VPS, не на serverless

- `users.db` — SQLite на диску;
- перевірка платежів Solana (фоновий цикл) в той самий процес/БД;
- довгі генерації.

### 3. Перед відкриттям власного домену

**а)** Блок reverse-proxy за зразком `deploy/series-lab/Caddyfile.staging`; якщо хост спільний з іншими сайтами, тримайте блок Lab окремим файлом і підключайте через `import`.

**б)** Бекап даних Lab: `deploy/series-lab/backup.sh` + cron через `install-backup.sh` (ставить `phase3.sh`). Offsite — лише з remote і парольною фразою.

**в)** Запас RAM на спільному хості (~3.8 ГБ): `free -m` / `docker stats` під генерацією.

### 4. Моніторинг

`health.yml` б’є `next.w3ir.io`, `gen.w3ir.io`, `studio.w3ir.io`. Для власного домену додайте його в `health.yml`.

### 5. Економіка на проді

На проді задайте в `.env` Lab lean-накладні й комісії (`HOSTING_MONTHLY_USD`, `SAAS_MONTHLY_USD`, `PAYMENT_FEE_PCT`, `FX_FEE_PCT`, `RESOURCE_FX_PCT`) — див. [ECONOMY.md](./ECONOMY.md). Адмін → Економіка читає живий `users.db`.

## Ключ Arweave на сервері

`IRYS_PRIVATE_KEY` живе лише в `.env` сервера, це окремий гаманець з малим балансом (не гаманець виплат). Кнопка Arweave в Експорті платить з нього й списує кредити етапу «архів». Для власного випуску користувач завантажує локально: `series upload --keypair` ([RELEASE.md](./RELEASE.md)). Пакети `@irys/*` — `optionalDependencies`; образ без них працює, лише без цієї кнопки.
