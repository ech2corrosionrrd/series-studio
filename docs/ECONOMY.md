# Економіка Series Lab

Юніт-економіка кредитів, накладні (хостинг + підписки) і обмін крипти→USD.  
Код: `src/platform/margin.mjs`, `src/platform/billing.mjs`. UI: **Адмін → Економіка**.  
Перевірка моделі: `node scripts/econ-check.mjs`.

> Користувач бачить **кредити**. Долари — на поповненні (USDC у Solana) і в адмінці (COGS / маржа).

## Пакети

| Пакет | USD | Кредити | $/кр |
|-------|-----|---------|------|
| Старт | 4.99 | 100 | ~0.050 |
| Креатор | 14.99 | 400 | ~0.038 |
| Профі | 29.99 | 1000 | **~0.030** (найдешевший) |

Оплата — USDC у Solana. Леджер: окремий `data/users.db`. Адреса оплат і ключі API — лише з `.env` Lab.

**Оплата USDC (Solana)** — без комісії платформи й посередника (лише мережева комісія відправника, копійки): гроші йдуть одразу на `SOLANA_PAY_RECIPIENT`. Сума замовлення = ціна пакета + до $0.01 унікальних мікро-центів (це ідентифікатор замовлення), кредити за пакет не змінюються. Тому `PAYMENT_FEE_PCT` (комісія платіжного провайдера) типово **0**.

У UI: кнопка **«Підтвердити в гаманці»** (Phantom підписує готову транзакцію) або вручну / deeplink. Сервер: `POST /api/credits/sol/prepare`.

RPC для перевірки переказів: `SOLANA_PAY_RPC_URL` / `SOLANA_RPC_URL`, інакше автоматично Alchemy (`ALCHEMY_API_KEY`), інакше публічний mainnet. Для Alchemy потрібен whitelisted Origin — типово `GENESIS_RPC_ORIGIN=https://mint.w3ir.io` (або додайте свій домен у кабінеті Alchemy).

## Тариф рушіїв (списання кредитів)

Правило підлоги: `ceil(costUsd × 50)` — 1 кредит @ $0.03 покриває ≥ **1.5×** вартості API.

| Сімейство | Draft / Final / Ref | Типовий COGS API |
|-----------|---------------------|------------------|
| Flux (fal, schnell, runware, pollinations…) | 1 / 2 / 2–3 | ~$0.003–0.025 |
| **Kontext Pro** (`kontext`, Replicate, $0.04) | мінімум **3** | $0.04 |
| Stability | 1 / 2 / 2–3 | ~$0.03–0.035 |
| OpenAI | 4 / 8 / 6–10 | ~$0.04–0.17 |
| **Local GPU** (ComfyUI / A1111) | `LOCAL_GPU_CREDIT_COST` (типово **1**) | **$0** API |

### Local GPU

- Доступний лише на ПК: `HOST=127.0.0.1` або `SERIES_LOCAL_GPU=1` (на хмарному сайті прихований).
- Обчислення — на GPU користувача; у `SERIES_MODE=public` списується плата підтримки Lab (`LOCAL_GPU_CREDIT_COST` кр/кадр).
- У леджері примітка: `Lab support · local GPU`.

Безкоштовний без списання кредитів: лише двигун **mock** (і етапи без генерації).

Вітальні кредити (`WELCOME_CREDITS`, типово 20) — разове нарахування при першому перевіреному вході. Другого безкоштовного гранту немає, і денної стелі на ці кредити немає: стеля безкоштовного — сам баланс вітання. Гаманець без оплати і без ручного нарахування додатково обмежений `GENERATION_RATE_LIMIT_PER_MINUTE` (типово 10 генерацій на хвилину). Оплата або грант цю похвилинну стелю знімає. Ціни пакетів не залежать від цього.

## Накладні та комісії

| Змінна | Що | Типово |
|--------|-----|--------|
| `HOSTING_MONTHLY_USD` | VPS (спільний хост) | **8** |
| `SAAS_MONTHLY_USD` | Irys / RPC / DNS buffer | **10** |
| `FIXED_MONTHLY_USD` | Якщо задано — **перебиває** суму hosting+saas | — |
| `PAYMENT_FEE_PCT` | Комісія платіжного провайдера на вхідний дохід (для прямого переказу USDC — 0) | **0** |
| `FX_FEE_PCT` | Вхід: USDC → ops USD (спред/комісія біржі чи обмінника) | **2** |
| `RESOURCE_FX_PCT` | Вихід: crypto → USD на оплату **API + VPS + SaaS** | **2** |

Чистий прибуток за період:

```
revenue
− API (оцінка COGS)
− комісія провайдера (PAYMENT_FEE_PCT × revenue)
− FX вхід (FX_FEE_PCT × revenue)
− фікс (пропорційно дням від HOSTING+SAAS або FIXED)
− обмін→ресурси (RESOURCE_FX_PCT × (API + фікс))
= net
```

Ціль: **невелика валова** на найжорсткіших рушіях (stability ~42%, kontext 3 кр ~56% при Pro $/кр; до 10.10.2026 Kontext коштував 2 кр, і валова на ньому була 33%, тонка після обміну й повернень); чиста додатна після фіксу вже з ~5× Старт/міс при lean overhead.

## Фактичні фіксовані витрати (10.10.2026)

| Стаття | $/міс | Примітка |
|---|---|---|
| VPS (Hetzner, спільний із іншими проєктами) | 8 | `HOSTING_MONTHLY_USD` |
| Буфер Irys / RPC / DNS (домен ≈ 1,2 входить сюди) | 10 | `SAAS_MONTHLY_USD` |
| Зовнішня копія бекапів: Cloudflare R2 | 0 | безкоштовні 10 ГБ/міс; наші копії (60 діб × ≈ 15 МБ) < 1 ГБ; понад ліміт 0,015 $/ГБ |
| **Разом** | **18** | модель і панель вже використовують саме це |

До 10.10.2026 копії лежали в Hetzner Object Storage (до 7,99 $/міс, ≈ 30% фіксованих витрат); їх перенесено на R2, bucket Hetzner видалено. Якщо знову потрібне платне сховище, додайте його до `SAAS_MONTHLY_USD` (або задайте `FIXED_MONTHLY_USD`), інакше панель завищуватиме прибуток.

**Чесний прибуток.** Платежі власних гаманців (оператор, команда, dogfood) це переказ самому собі, а не дохід. Панель показує два числа: «Чистий прибуток» (усі платежі, як раніше) і «Чистий без внутрішніх платежів» (`net_profit_external_usd`: дохід лише зовнішніх платників проти всіх витрат, бо тестові виклики API теж реальні витрати). Для рішень орієнтуйтесь на друге.

## Admin → Економіка

`GET /api/admin/economy?days=7|30|all` (лише адмін-гаманець).

Показує:

1. Огляд леджера (гаманці, дохід, кредити в обігу, ARPU).
2. Період: валова / оцінка API / utilization / чистий прибуток + розбивка комісій і обміну.
3. Беззбитковість (пакет Старт): внесок і скільки потрібно на місяць.
4. Накладні + **сценарії Pro×N** (мікс 70% flux / 15% openai / 15% local).
5. Юніт-модель: пакети, тариф сімейств, COGS рушіїв vs $/кр.
