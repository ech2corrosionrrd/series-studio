name: state
description: Короткий стан проєкту - гілка, незакомічене, відкриті PR, останні запуски CI/деплою, відкриті пункти ROADMAP. Для старту сесії.
---

Зведи стан одним повідомленням (до 15 рядків), нічого не змінюючи:

1. `git status --short`, `git branch --show-current`, `git log --oneline -5`.
2. `gh pr list` - відкриті PR.
3. `gh run list --limit 5` - останні запуски (деплой сайту, health).
4. Відкриті пункти таблиці в `docs/ROADMAP.md` (рядки зі статусом «відкрито»), з пріоритетом P0 першими.
5. Якщо є пам'ять проєкту (`project-state-*`), звір числа (тести, команди, маршрути) з `npm run docs:check`; розбіжність - познач.

Закінчи однією рекомендацією, що робити першим.
