# Дипломний проєкт «Series Lab»: пакет документів

Це повний комплект документації для дипломної роботи за темою:

**«Веб-система Series Lab для створення, перевірки й підготовки до випуску колекцій NFT: детермінована генерація, перевірений архів і безпечна публічна платформа з оплатою в USDC»**

Усі тексти створено за допомогою штучного інтелекту (Claude, Anthropic) на основі реального коду й документації репозиторію `series-studio` (версія 1.8.0). Усі числа, імена модулів, маршрути й таблиці взято з цього репозиторію. Позначки `[…]` у квадратних дужках потрібно замінити власними даними (ПІБ, ЗВО, кафедра, керівник, рік).

> **Важливо для студента.** Перед поданням прочитайте все, перевірте кожне твердження за кодом і джерелами, перепишіть своїми словами те, що ви не можете пояснити на захисті, і дотримуйтесь вимог вашого закладу освіти щодо використання ШІ (див. [`12-deklaratsiya-pro-vykorystannya-ShI.md`](./12-deklaratsiya-pro-vykorystannya-ShI.md)).

Збірка в один документ Word: `python build_docx.py` (див. нижче).

## Як зібрати `.docx`

```
pip install python-docx
python diploma/build_docx.py
```

Результат: `diploma/Dyplom_Series_Lab.docx`. Скрипт застосовує типові вимоги до оформлення (Times New Roman 14 pt, інтервал 1,5, поля 30/15/20/20 мм, нумерація сторінок, заголовки розділів з нової сторінки). Схеми Mermaid у тексті лишаються кодом: для друку відрендеріть їх (наприклад, на mermaid.live) і вставте як зображення.
