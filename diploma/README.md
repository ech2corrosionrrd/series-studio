## Як зібрати `.docx` і `.pptx`

```
pip install python-docx pillow
python diploma/render_figures.py   # оновлення схем (за потреби)
python diploma/build_docx.py       # збірка повного Dyplom_Series_Lab.docx
node diploma/build_pptx.mjs        # збірка презентації Dyplom_Series_Lab_Zahyst.pptx
```

**Перед збіркою закрийте `Dyplom_Series_Lab.docx` у Word** (інакше файл збережеться в `Dyplom_Series_Lab_fresh.docx`). Після `build_docx.py` відкрийте `diploma/Dyplom_Series_Lab.docx` — у ньому міститься **21 рисунок** (контекстна діаграма, життєвий цикл, дерево цілей, архітектура, ER-діаграма, блок-схема взаємодії, скріншоти лендінгу, входу, майстерні, генерації, експорту, деплою, діаграма оплати USDC, CI/CD, Docker, діаграми вартості й окупності 5.1–5.2, діаграми додатків Б.1–Б.4).

Результат: `diploma/Dyplom_Series_Lab.docx` (≈ 3–4 МБ, 21 вбудований рисунок). Оформлення: Times New Roman 14 pt, інтервал 1,5, поля 30/15/20/20 мм, нумерація сторінок; **новий розділ (Heading 1) — з нової сторінки** (один розрив, без порожніх сторінок між файлами). Блоки Mermaid замінюються зображеннями з `figures/`.
