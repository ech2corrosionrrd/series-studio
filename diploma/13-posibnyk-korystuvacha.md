# ПОСІБНИК КОРИСТУВАЧА

Series Lab допомагає створити колекцію NFT: від базової картинки до перевіреного архіву й набору для випуску. Посібник написано простими словами; докладніші версії є у вбудованій довідці («Довідка» у верхній панелі) та в `docs/GUIDE.md`.

## 1. Що потрібно

- Комп'ютер із сучасним браузером.
- Для **публічного сервісу**: гаманець (MetaMask, Coinbase Wallet або Phantom) — для входу підписом повідомлення. Паролі й пошта не потрібні.
- Для **локального запуску**: Node.js 22.13 або новіший, папка проєкту; запуск — `start-lab.bat` (Windows) або `npm start`. Інтерфейс відкривається на `http://127.0.0.1:5344/`.
- Для **випуску в Solana**: ключі лише на вашому ПК (CLI), інструмент `mplx`, трохи SOL для комісій і зберігання.

> Ключі від гаманця **ніколи** не вводяться в інтерфейс. Якщо сторінка просить seed-фразу, це шахрайство.

## 2. Вхід і кредити (публічний сервіс)

1. Відкрийте сторінку входу, оберіть гаманець і підпишіть повідомлення. Перший вхід дає разові вітальні кредити.
2. Кредити потрібні для платних кадрів. «＋ Купити» відкриває вікно поповнення: оберіть пакет, надішліть **точно** показану суму USDC у мережі Solana на показану адресу (або натисніть «Підтвердити в гаманці»). Кредити зараховуються самі, зазвичай за хвилину.
3. «Запросити друга»: ваше посилання; коли запрошений уперше купить кредити, ви отримаєте бонус.
4. «Мої дані» видаляє ваші файли й записи використання (потрібно ввести `DELETE`); облік грошей лишається.

## 3. Швидкий старт за 10 хвилин і $0

Рушій `mock` малює прості кольорові заглушки — тренажер без витрат.

1. **Огляд.** Назва «Test», ID `test` → «Почати серію».
2. **Основа.** Завантажте будь-яку картинку з роллю «Головна базова».
3. **Конструктор.** Оберіть пак `pfp-core` → «Застосувати пак» → «Зберегти промпт+трейти».
4. **Рецепти.** «Зібрати тексти» (без кредитів).
5. **Генерація.** Рушій `mock`, «Пілот N» = 5 → «Порахувати (безкоштовно)» → «Згенерувати…».
6. **Відбір.** Позначайте ✓ / ↻ і «Перегенерувати відхилені» — з'являться версії v·2.
7. **Експорт.** «Перевірити чекліст» і «Зібрати ZIP».
8. Далі вкладки **Деплой** і **Маркет**.

## 4. Покроковий путівник

| Вкладка | Що робите | Що отримуєте |
|---|---|---|
| 1 · Огляд | Назва, ID, кількість, зерно, рушій. Галочка «База — частина колекції (видання #0)». | `presets/<ID>.json` |
| 2 · Основа | Завантажуєте або генеруєте базову картинку; за потреби «Vision Assist» розбирає стиль. | основа серії |
| 3 · Конструктор | Шаблон запиту, пак рис, редактор опцій, `styleLock`. | промпт і риси |
| 4 · Рецепти | «Зібрати тексти»: таблиця DNA, рідкість, `diff-seed`, хвилі, точкові правки. | архів рецептів |
| 5 · Генерація | Оцінка ціни → «Згенерувати». Пілоти, прогрес у реальному часі, «Скласти шари». | картинки |
| 6 · Відбір | Keep/redo, версії, кошик, порівняння, схожість. | відібраний набір |
| 7 · Експорт | «Перевірити чекліст» → «Зібрати ZIP» (архів випуску). Помилки блокують ZIP. | ZIP із зображеннями й метаданими |
| Деплой | «Зібрати набір деплою»: конфіги й команди. | ZIP з `DEPLOY.txt`, оцінкою витрат |
| Маркет | «Зібрати набір маркетплейсу»: тексти, розміри, чеклісти. | ZIP для майданчика |

## 5. Ціна до дії

Перед платною генерацією система показує оцінку. «Згенерувати» стає доступною після безкоштовного «Порахувати». Помилка генерації повертає кредити. Денна межа витрат і автостоп після серії помилок оберігають від випадкових витрат.

## 6. Випуск у Solana (на вашому ПК)

Після набору деплою виконайте в папці проєкту (команди підписує ваш локальний ключ; сервер ключ не бачить):

```
node bin/series.mjs release-init out/demo-archive.json -o release.json --creator <адреса> --price 0.2
node bin/series.mjs upload <тека-набору> --keypair deployer.json --dry-run
node bin/series.mjs upload <тека-набору> --keypair deployer.json
node bin/series.mjs hidden <тека-набору> --uri <посилання-hidden.json>
node bin/series.mjs guards release.json --allowlist wallets.txt
node bin/series.mjs verify release.json
node bin/series.mjs mint release.json --keypair minter.json
node bin/series.mjs reveal <тека-набору> --keypair creator.json
```

Починайте з **devnet**. `upload` відновлюється після обриву (файл `cache.json`).

## 7. Часті запитання

| Питання | Відповідь |
|---|---|
| Персонаж щоразу різний | Візьміть чіткішу базову картинку; підніміть силу референсу до 0,5–0,65; пропишіть у «Лишити» ключові риси. |
| Скільки коштує серія? | Натисніть «Порахувати»: побачите точну оцінку. |
| Як не витратити забагато? | Денна межа витрат; пілот із 5–12 кадрів; рушій `mock`. |
| Як видалити свої дані? | «Мої дані» → введіть `DELETE`. |
| Де умови користування? | Посилання на сторінці входу. |
