# ПЕРЕЛІК УМОВНИХ ПОЗНАЧЕНЬ І СКОРОЧЕНЬ

| Скорочення | Розшифрування |
|---|---|
| NFT | Non-Fungible Token — невзаємозамінний токен |
| DNA | у системі: впорядкований рядок значень рис елемента колекції, що визначає його унікальність |
| PRNG | Pseudo-Random Number Generator — генератор псевдовипадкових чисел |
| FNV-1a | Fowler–Noll–Vo, варіант 1a — нехриптографічна хеш-функція |
| mulberry32 | швидкий 32-бітний PRNG |
| SHA-256 | криптографічна хеш-функція родини SHA-2 |
| HMAC | Hash-based Message Authentication Code |
| SIWE | Sign-In with Ethereum, стандарт EIP-4361 |
| EIP | Ethereum Improvement Proposal |
| ERC-721 | стандарт NFT в Ethereum |
| SPL | Solana Program Library |
| USDC | стабільна монета, прив'язана до долара США |
| RPC | Remote Procedure Call — виклик віддаленого вузла блокчейну |
| CMC / Core Candy Machine | програма Metaplex для випуску колекцій у Solana |
| Candy Guard | набір правил мінту (ціна, дата, ліміт, список дозволених) |
| Irys | сервіс оплати постійного сховища Arweave |
| Arweave | мережа постійного зберігання даних |
| SQLite | вбудована реляційна СУБД |
| WAL | Write-Ahead Logging — режим журналу SQLite |
| CSRF | Cross-Site Request Forgery |
| API | Application Programming Interface |
| CLI | Command-Line Interface |
| SSE | Server-Sent Events |
| CI | Continuous Integration — безперервна інтеграція |
| CI/CD | Continuous Integration / Continuous Deployment — безперервна інтеграція та доставка |
| COGS | Cost Of Goods Sold — собівартість |
| ARPU | Average Revenue Per User — середній дохід на користувача |
| i18n | інтернаціоналізація (uk/en) |
| aHash | Average Hash — алгоритм обчислення перцептивного середнього хешу |
| DDL | Data Definition Language — мова опису структур даних |
| ВДТ | візуальний дисплейний термінал |
| ЗВО | заклад вищої освіти |
| ШІ | штучний інтелект |
| ТЗ | технічне завдання |
